# 半成品库、组织权限与页面交互

## 原液与库位

酿造完成、包装完成、成品放行入库分别记录。原液仍在发酵罐或清酒罐内时，罐体继续占用，实际位置使用罐体关联的半成品库位；不能同时在另一个库位重复增加相同库存。

在「系统设置 → 仓库」选择厂区，新增仓库时选择「半成品 / 原液库」，再在「管理库位」中增加实际存储位置。确实转移了酒液，才按实际数量办理移动。新增罐体会关联库存库位；历史批次的位置缺失须现场核对，系统不推测原液去向。

包装页把「包装任务」「待包装原液」「待放行」分开。生产管理人员可从完成酿造的原液创建包装安排，指定材料、执行人和时间。包装材料任务完成记录与成品入库记录仍分别保留；材料登记本身不代表成品已入库。当前一个生产计划对应一个包装任务，分批多次包装尚未扩展为多个独立任务。

批次详情中的「追加包装」「关联客户」分别打开独立弹窗。取消舍弃当前编辑，保存成功刷新批次，失败在弹窗内显示原因。

## 总部与厂区

组织树为「总部 → 厂区 → 部门 → 车间 / 班组」，总部也可以有直属部门。总部身份由组织归属确定，实际操作权限由角色决定。厂区账号的数据范围固定为所属厂区，分配多个角色不会扩展到其他厂区。

总部用户管理默认显示组织人数概览，点击厂区或部门查看人员。厂区账号只查看本厂组织和人员；本厂负责人可以管理本厂普通账号，不能给账号授予总部管理角色或调整其他厂区。历史未明确归属的账号单列「待分配组织」，不自动猜测其归属。

本轮在 API 服务层统一了生产、库存、采购、任务、报表和组织用户的厂区范围。客户、供应商、原料、酒品等企业共享主数据仍按企业共享；没有将其改成独立的厂区档案。Odoo 后台原生记录规则并非本轮全面迁移的范围。

## 信息与视觉层级

- 库存采购总览：四项紧凑待办 → 有异常才出现的关注提示 → 全宽材料表 → 原液列表。
- 搜索筛选：与标题同栏，常用控件统一为 34px，窄屏自动换行。
- 用户角色：角色对应固定的低饱和配色，圆角小标签；组织继承角色增加虚线边框，悬停说明来源。
- 主导航：展开显示图标和名称，收起宽度 64px；保留高亮、任务提示、悬停名称和账户入口，浏览器记住用户选择。首次在窄屏进入默认收起。
- 罐体详情：先显示当前产品、批次、实际在罐量和剩余容量，再显示累计实际产量、完成批次和最近完成日期。隐藏清洗状态字段及通用说明横幅。
- 罐体累计统计来自全部授权范围内的已完成批次；历史列表先展示最近六批，不能将这六批的小计当累计值，也不使用计划产量代替实际产量。
